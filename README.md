## 1. Project Overview

The Tacos Locos website is a responsive business website made to give customers an easy and engaging way to learn about Tacos Locos, check out the menu, view services, and send enquiries.

The goal is to build a stronger online presence for the business while showing off its food, brand identity, and services in a clear and professional way.

The website is being built using **HTML, CSS, and JavaScript**. HTML is used for structure and content, CSS handles styling and responsiveness, and JavaScript adds interactive features where needed.

---

## 2. Website Goals and Objectives

The main goals and objectives of the Tacos Locos website are:

* Create a professional online presence for Tacos Locos.
* Make it easy for customers to view the menu.
* Share information about the business and its services.
* Help customers contact the business easily.
* Provide a simple enquiry option for questions or requests.
* Build a clean and user-friendly interface.
* Make sure the website works well on all screen sizes and devices.
* Organise content into clear, easy-to-navigate sections.
* Help more people discover Tacos Locos online.

---

## 3. Key Features and Functionality

The website will include the following key features:

### Home Page

The home page will welcome visitors to Tacos Locos and give quick access to the main sections of the site.

### About Page

The About page will explain what Tacos Locos is about and what the business offers.

### Services Page

The Services page will show the different services provided by the business.

### Menu

The menu section will display the food and drinks available at Tacos Locos in a clear and organised way.

### Enquiry Page

The enquiry page will let users send questions or requests using a simple form.

### Contact Page

The contact page will show the business’s contact details and how customers can get in touch.

### Navigation

A navigation menu will make it easy for users to move between pages.

### Responsive Design

The website will be designed to work smoothly on desktops, tablets, and mobile devices.

## 5. Part 1 Details

Part 1 is all about setting up the basic structure and content of the Tacos Locos website.

The initial website includes separate HTML pages:

* `index.html` — Home page
* `about.html` — About page
* `service.html` — Services page
* `enquiry.html` — Enquiry page
* `contact.html` — Contact page

These pages are linked together using a consistent navigation system.

The main objectives for Part 1 are:

* Create the required HTML pages.
* Set up a clear website structure.
* Add relevant content to each page.
* Link all pages together with navigation.
* Include suitable images and business information.
* Create the initial sitemap.
* Keep the HTML clean, structured, and easy to read.

**Part 2 and Part 3:** Later updates will include styling, functionality, testing, and final improvements, which will be documented as the project continues.
